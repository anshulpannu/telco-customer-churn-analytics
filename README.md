# Telco Customer Churn Analytics

## Overview

This project analyzes customer churn for a fictional telecommunications company providing home phone and Internet services.

The dataset contains 7,043 customers in California during Q3, with information covering customer demographics, tenure, subscribed services, contracts, billing, charges, churn status, customer lifetime value, and churn reasons.

The main objective is to understand why customers leave, identify customer segments with higher churn, and determine where retention efforts could have the greatest impact.

## Approach

This is primarily a SQL-based analytics project. The work will include data profiling, data cleaning, exploratory analysis, customer segmentation, and analysis of churn and customer value.

Power BI will be used later to present the main findings in a business-focused dashboard.

## Tools

The main tools used in this project are SQL, Power BI, Excel, Git/GitHub, and Visual Studio Code.

## Key Questions

The analysis will focus on questions such as:

* What is the overall churn rate?
* Which customer segments have the highest churn?
* How does churn vary by contract and tenure?
* Which services are associated with higher or lower churn?
* How do monthly charges and customer value relate to churn?
* What are the main reasons customers leave?
* What retention opportunities can be identified?

## Dataset

The dataset was obtained from Kaggle and contains 7,043 customer records and 33 variables.

The original dataset is stored in the `data/raw` folder. Details about the fields and data preparation considerations are documented in `documentation/data_dictionary.md`.

## Project Structure

The repository contains the original and cleaned datasets, SQL scripts, project documentation, Power BI files, and supporting screenshots or exports.

The project is currently in the setup and data documentation stage. Data profiling and preparation will be completed before beginning the main SQL analysis.
